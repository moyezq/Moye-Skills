# Windows 桌面应用界面

壳这一层的入口：窗口、材质、输入、密度、动效、上线审计。页面内部（组件怎么拆、布局怎么写、React 怎么组织）走 `self-frontend`，本文件不复述。

完成标准：五步走完，每处「网页默认」都判过是留还是换，最后逐条过了 `references/ship-audit.md`。

## 一条判据贯穿全程

**问等价的 Windows 原生控件在这里怎么做，照做。**

用户的手感来自他天天用的那些 Windows 程序，不来自网页。列表行、普通按钮、工具栏图标、输入框、右键菜单各有各的约定。错不在「悬停太多」或「悬停太少」，错在**统一处理**——所有控件套同一套悬停样式，正是网页的味道。

例外只有一处：**平台默认主动破坏原生感时，精确覆盖那一处**。WebView 的默认行为是为嵌入网页设计的，不是为原生界面设计的：光标变手型、浏览器右键菜单、文字可选中、平滑滚动、拼写红波浪线都属于这一类。覆盖它们，其余交给系统——系统的模糊比你的快，系统的滚动条比你的对，系统的焦点环比你的跟得上用户的其它程序。

## 先扫「网页味」

写第一行代码前扫一遍，做完再改代价高得多。逐条判：留下，还是换掉。

| 网页默认 | 桌面做法 |
|---|---|
| `cursor: pointer` 标可点 | 光标保持不变（真可拖拽的句柄除外） |
| 全站文字可选中 | chrome 禁选，只有内容区与输入区可选 |
| `scroll-behavior: smooth` | `behavior: 'auto'`，即时到位 |
| 路由之间淡入淡出 | 直接切，原生窗口不淡入 |
| 快操作配骨架屏 | 200ms 内什么都不显示，之后转圈 |
| DOM 自绘模态 + 遮罩模糊 | 系统对话框；设置开独立窗口 |
| 网页 toast | 系统通知中心 |
| CSS `box-shadow` 画窗口阴影 | 系统画 |
| CSS `border-radius` 画窗口圆角 | 系统画 |
| 硬编码品牌蓝当强调色 | 跟系统强调色 |
| `clamp()` / `vw` 流体标题 | 固定 rem 阶梯 + 容器查询 |
| 44px 触控目标 | 鼠标目标 24–32px，命中区用透明 padding 撑 |
| 多步 onboarding 引导 | 界面自解释；首次悬停给 tooltip，之后不再出现 |

## 五步

### 1 定窗口外壳

标题栏归谁、要不要自定义材质、窗口位置记不记、托盘与全局热键怎么起。**先查能拿到什么再画**：材质、原生右键菜单、单一实例、IME 候选框在三个栈上的可达性不同。

指针 → [`references/shell-windows.md`](./references/shell-windows.md)（写窗口、标题栏、材质、托盘、热键、右键菜单、拖放、系统集成时读；启动白闪、后台节流、IME 出错时按症状查它）

完成标准：窗口与焦点、材质、系统集成三块都在该文件里逐条过过；拿不到的条目写进「已知取舍」，不是忘掉。

### 2 定画面系统

排版阶梯、间距刻度、色彩语义角色、深浅色主题。密度按桌面定，不按移动端——桌面专业工具的价值就在一屏装得下多少。

指针 → [`references/visual-system.md`](./references/visual-system.md)（排版、间距、密度、色彩、深度、主题、浏览器表面主题化）

完成标准：语义角色齐备且对比度过门槛（正文 ≥4.5:1，大字与控件 ≥3:1）；间距有文档化的刻度，没有一次性魔法值。

### 3 定交互手感

动效的决策链是「该不该动 → 目的 → 曲线 → 时长」，不是先挑时长。悬停按控件分档，按压态必须有，状态矩阵齐备。

指针 → [`references/interaction-craft.md`](./references/interaction-craft.md)（加动效、调手感、写加载/空/错误态、改界面文案时读）

完成标准：每个交互组件的 default / hover / focus / active / disabled / loading / error 都指得出实现；每条动效说得出它解决什么。

### 4 键盘与焦点走一遍

拔掉鼠标把主流程走完：Tab 顺序按视觉而非 DOM、Esc 在每个浮层都有作用、列表里敲首字母能跳、焦点环可见且跟系统。桌面用户里键盘重度用户的比例远高于网页。

完成标准：主流程全程不用鼠标能完成；Esc 在任何可关闭的东西上都有作用。

### 5 上线前审计

指针 → [`references/ship-audit.md`](./references/ship-audit.md)（宣称「差不多了」之前读；按节打分，A–G 的红项是发布阻断）

完成标准：A–G 无红项，H / I 的遗留已记录；定级与分诊顺序按该文件的规则。

## 三个栈各能拿到什么

本文不替你选栈。选定之后照这张表知道哪些条目能直接落、哪些要绕路。

| | WebView2（宿主自写） | Electron | Tauri |
|---|---|---|---|
| 系统材质（mica / acrylic） | 直接：`DwmSetWindowAttribute` + `DWMWA_SYSTEMBACKDROP_TYPE` | 要原生模块 | 要原生模块 |
| 原生右键菜单 | `CoreWebView2.ContextMenuRequested` | 拦截 + 原生菜单 | 拦截 + 原生菜单 |
| 单一实例 | 自己写 | `requestSingleInstanceLock` | 内置 |
| 全局热键 | 自己写 | `globalShortcut` | 内置插件 |
| 托盘 | 自己写 | 内置 | 内置 |
| IME 候选框贴合插入符 | 要处理焦点归属 | 通常正常 | 通常正常 |
| 窗口位置记忆 | 自己写 | 自己写 | 内置插件 |

标「自己写」的格子，[`references/shell-windows.md`](./references/shell-windows.md) 里都有具体修法。

## 字体

**界面文字用系统字体**（`'Segoe UI Variable', 'Segoe UI'`），自定义字体只给启动页与品牌展示位。

桌面界面的成功标准是用户把事办完：可扫描性、一致性、跟系统一致，压过表达欲。自定义字体在数据密集界面拖低可读性，也加重「像网页」的观感。品牌要露脸的地方——启动页、关于页、空状态插画——是展示位，那里可以用自定义字体。

## 不做的

- 不替人选栈，不搬上游的四层架构、UniFFI、内存核算：那是选型与后端。
- 不带 CLI、hooks、项目内状态产物：本 skill 只靠正文与 references 就能执行。
- 移动端条目（iOS / Android 规范、触控目标、安全区）不在本文。
- 不碰页面内部：组件拆分、布局、React、仿站走 `self-frontend`。

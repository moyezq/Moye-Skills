# 会话工具

三件事各一份细则。先认场景，再只读对应那一份。

## 认场景

| 情形 | 读 |
|---|---|
| 自检本轮操作 / token / skill 加载 | `references/audit.md` |
| 写交接或从交接接续 | `references/handoff.md` |
| 本轮经历 → 可迁移面试题 | `references/interview.md` |

完成标准：已说出是哪一件，且已 Read 上表对应文件；没有用本文件代替那三份执行。

## 何时不用

- 新对话开场、全程硬约束 → 会话索引（禁止改它）
- 分析上游/本地 skill、写 analyse 报告 → skill 分析报告
- 记本仓决策/术语/目标架构 → 写 `CONTEXT.md` / `docs/adr.md` / `docs/architecture.md`
- 写笔记库 → 知识库文档

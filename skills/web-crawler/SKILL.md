# 取当前页：先定两份状态

本文件只做**选路**。取页手法按窗口拆成能力细则；目前落地的是「用户 Chrome 列标签并取当前页」，以及同一条连接上拦即将发出的请求。

动手看网页之前，分开记两件事，不要混成一次「打开试试」：

| 状态 | 问的是 | 最短取法 |
|------|--------|----------|
| **匿名状态** | 空身份打这个 URL，进不进得了业务页 | 一次跟随跳转的 HTTP GET |
| **会话状态** | 眼前这个已开窗口，现在是登录墙还是业务页 | 列已有会话，对已打开目标站的那一个取一帧 |

三种窗口不要混：

| 窗口 | 登录态属于谁 |
|------|----------------|
| 匿名 HTTP | 没有浏览器 Cookie |
| harness 自带浏览器 | 该 harness 自己的 Cookie 罐，不是用户日常浏览器 |
| 用户本机 Chrome / Edge | 用户正在用的配置 |

本文件管到「当前页数据在手」为止。

## 何时用 / 何时读细则

**用**：必须看见真实页面才能判断数据在哪；还不知道这个站匿名能不能进；准备开 harness 自带浏览器或无窗口 CLI 去目标站；要接到用户已打开的已登录页。

**不用**：URL 已知且匿名 HTTP 已经拿到业务字段（直接解析，不必开浏览器）；只改本地代码。

| 能力 | 何时读 |
|------|--------|
| 用户本机 Chrome / Edge：列标签并取当前页 | [references/chrome-tabs.md](references/chrome-tabs.md) |
| 用户本机 Chrome：同一条连接拦请求 | [references/chrome-network.md](references/chrome-network.md) |

完成标准：命中上表时已经读完对应文件再动手。

## 1. 匿名状态：一次跟随跳转的 GET

对**用户要的那个 URL**发一次 GET，跟随跳转。记下三样：状态码、最终 URL、正文是登录壳还是业务数据。同一站点不同路径各自判定，不把一个 URL 的结论复用到另一个。

判定（有一条就定「要登录」）：

* 最终 URL 的 path 含 `login` / `signin` / `passport` / `account`，或 query 带 `redirect` 指回原地址
* 正文是手机号、密码、二维码、验证码，没有本次要的业务字段

判定「匿名可进」：最终 URL 仍是目标路径（或明显的业务路径），正文里已经有要的字段或列表结构。

匿名请求按「到达 HTTP 层」计数：连接或 TLS 失败不计入，也不改写匿名状态。同一 URL 到达 HTTP 层的匿名 GET 至多 1 次。最终 URL 已经是登录页，匿名状态就定了。

```text
✅
GET https://www.example.com/feed
→ 200，最终 URL = /login?redirectPath=/feed，正文是手机号登录
结论：要登录。停止匿名请求。

❌
GET 已跳到 /login，再开空白浏览器访问同一个 /feed

❌
harness 自带浏览器里已经登录，就宣布「这个站不用登录」
```

HTTP 仍落在目标 URL、但正文只是空壳、看不出登录还是业务时：才允许用**空白**浏览器打开这一次作补证。补证后同样写入匿名状态，不再开第二次空白。

完成标准：书面结论是「匿名可进」或「要登录」二者之一；该 URL 到达 HTTP 层的匿名 GET 次数为 1（空壳补证至多再加一次空白打开）。

---

## 2. 会话状态：列一次已有浏览器

匿名状态写完后，**先列、再决定开不开新的**。三类分开记，不要合成一条「本机有浏览器」：

1. harness 已开标签（该 harness 的列标签 / 快照）
2. CLI 已有会话
3. 用户本机 Chrome / Edge（读 `references/chrome-tabs.md`）

每条只记四态之一：**未开目标站 / 开着但是登录墙 / 开着且有业务数据 / 超时不可用**。

接入与列标签类命令各自带上限（默认 60 秒）。超时不重试，判「该接入点不可用」，换清单下一条；清单走完仍无可用会话，才向用户要窗口。60 秒握手失败的默认解释是：远程调试弹了 Allow，用户没点到。不要当程序错误、网络错误或端口错误去排，也不要立刻再握一条。

```text
✅ harness 标签停在目标站且能看见业务标题 → 会话=该 harness 已登录；取这一页。不要写成「用户 Chrome 已登录」
✅ 用户 Chrome 可接入、目标站标签有业务数据 → 会话=用户浏览器已登录；走 chrome-tabs 取页
✅ 清单为空或全是超时不可用 + 匿名要登录 → 问用户做一次接入准备（下一节）
✅ 60 秒超时 → 请用户点 Allow，本轮停
❌ 清单还没列，先用空白配置（harness 新开或 CLI `open`）去目标站
❌ 要登录已经定性，换一种空白配置再试
❌ 60 秒超时 → 换 playwright-cli / 再 new WebSocket / 查防火墙
```

完成标准：三类窗口各有记录；每条是四态之一；没有在列清单之前空白新开。

---

## 3. 选路（两份状态填完再动浏览器）

| 匿名 | 会话 | 做 |
|------|------|-----|
| 可进 | 任意 | HTTP 正文已够就取 HTTP；还要渲染后再取时，空白开一次即可 |
| 要登录 | 某窗口开着且有业务数据 | 接入**那一个**窗口，取当前页 |
| 要登录 | 开着但是登录墙、未开、或超时不可用 | 请用户做**一次**接入准备，然后接入。本轮不再空白新开 |

用户可接受的一次性操作（整场任务各至多一次）：在已登录环境打开目标页；打开远程调试开关；对接下来那一条调试连接点 Allow。点过之后，列标签和取页必须复用这一条连接，禁止为同一次取数再握手。

```text
✅ 用户点一次 Allow → 同一条连接上列标签并 eval → 断开
❌ 每列一次标签、每 eval 一次就新建一条调试连接
❌ 关掉用户的外部浏览器
```

完成标准：实际打开或接入的次数符合上表；要登录且无可用会话时，已经向用户要过一次接入准备，而不是自己又开了空白页；调试连接在本轮取数期间只建立过 1 条。

---

## 4. 取当前页（本 skill 在此结束）

从**当前接入的那一页**取出：

1. 最终 URL、标题
2. 这一页是登录墙还是业务页（与第 2 步交叉核对）
3. 任务相关数据：可见文本，或页面脚本里已经带着的状态对象

能 `eval` 就取结构化字段；只要快照里已经有要的字，快照也算拿到。取完断开连接；不要关掉用户的外部浏览器。

取出的任务字段若为空，先把原文切片落盘（HTML 或 `Runtime.evaluate` 的原始字符串），再判断登录。

* 原文里已经有探针或身份字段 → 这是解析，不是会话过期。禁止为这个结果再握一条调试连接。
* 登录只看身份字段。列表长度、和匿名 GET 比条数，都不能当登录判据。

还需要「这一页即将发出的请求字节」时：读 `references/chrome-network.md`，在**已经打开的那一条**连接上开 Network 域。不要为采样再握手。

```text
✅ 接入已登录会话，eval 出列表标题与当前 URL，停
✅ 列表 0 条 → 存原文 → 看见 `undefined`/`new Map` → 改解析
✅ 一条连接：列标签 → eval 当前页 → 同一条上拦下一条 XHR
❌ 拿到第一屏之后继续滚动、点详情、写爬虫脚本
❌ 在登录墙页面里填账号密码代用户登录
❌ 列表 0 条 → Cookie 过期 → 再连一次 CDP
❌ 每个子步骤各 new 一条 WebSocket
```

完成标准：上面三样都有；没有代登录；没有对同一目标站再开空白浏览器；没有为取这三样再开第二条调试连接；空字段时已经落盘原文且没有为此再握手。

## 邻域入口

playwright-cli 自己 `open` 就能点完的界面测试走 `playwright-cli`。要接到已经在跑的浏览器、或依赖用户日常登录态取当前页时，只接用户本机 Chrome / Edge（`references/chrome-tabs.md`）。Harness 自带浏览器用该 harness 的列标签、锁定、导航、执行页面 JS。

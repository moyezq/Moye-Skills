# 前后端同仓目录

前后端分离且归在同一仓库时读本文。通用规则仍生效。

1. 前端统一放在 `frontend` 文件夹下；后端统一放在 `backend`。
2. 前端或后端有多服务时，第二级是服务名文件夹；单服务不需要这一级。
3. 再下一级是架构层，例如 RAG 服务的 Query Embedding、Semantic Retrieval、Reranking。
4. 再下一级是模块层，例如文件抽取层分为文件下载、文件基础信息读取、文件按类型读取、内容关键信息抽取、内容分块。
5. 后端启动文件仍放在仓库根，命名遵守通用规则第 4 条。不要把 `python` 启动入口写进 `backend/` 子目录。
6. 只被一个模块使用的工具放在该模块目录。被同一服务多个架构层共用的，在该服务文件夹下建 `utils/`。

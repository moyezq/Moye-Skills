# 画面系统

排版、间距、密度、色彩、深度、主题。目标是「被做出来的」，不是「拼出来的」。

数值是起点不是铁律；偏离时说得出口服人的理由。

## 排版

- **正文 16px 起**，14px 只给次要文字（时间戳、辅助说明）。桌面视距比手机近，但窗口里信息更密，缩到 14px 以下会累。
- **正文行宽 65–75ch**。表格与数据区可以到 120ch 以上——那是在比数，不是在读句子。
- **用固定 rem 阶梯，不用 `clamp()` / `vw` 流体标题**。桌面窗口宽度可以任意拖，流体标题在窄窗口里会把侧栏的 h1 缩到看不出层级；要在不同窗口宽度下切换尺度就用容器查询，不要用视口单位。
- **阶梯比例 1.125–1.2**，相邻标题层级之间有明显跳跃，不要出现三个几乎一样大的标题。
- **display 最大 6rem，字距下限 -0.04em**（再紧就开始糊）。
- **深底浅字三轴补偿**：行高略放大、字距略放松、字重加一档。浅字在深底上视觉上会变细，不补就是发虚。
- **一套无衬线家族通常够用**；等宽只给代码、数据、度量，不当「技术感」的戏服。
- **只加载用到的字重**，给出 metric 兼容的回退字体，`font-display: swap`。

## 字体取向

**界面文字用系统字体**（`'Segoe UI Variable', 'Segoe UI'`）。自定义字体只给启动页、关于页、空状态插画这类展示位。

为什么：桌面应用的成功标准是用户把事办完。系统字体在每一种字号与 DPI 下都调好了，跟用户的其它程序一致，中英混排不会出怪间距。自定义字体在数据密集界面拖低可读性，也让整个界面更像网页。

## 间距与节奏

- **有文档化的间距刻度**（4 单位基数比纯 8 刻度好：8 缺中间那一步），并用语义化的间距角色（组内 / 组间 / 区块间），不要满屏一次性魔法值。
- **标题上方的空间大于下方**，这条把标题和它管的内容绑在一起。
- **同组紧、异组松**。节奏来自「紧—松」的有意对比，不是把同一个值刷满整屏。
- **兄弟间距优先用 `gap`**，不用子元素 margin 叠。
- 视觉补偿只在看过渲染结果之后做，不要预先补。

## 信息密度（桌面特有）

移动端那些「一屏最多四个选项」的上限不要照搬。桌面专业工具的价值恰恰在一屏装得下多少：数据表、属性面板、菜单栏、命令面板都是高密度界面。

- **密度跟随使用频率与决策复杂度**：天天用的操作排得紧，一个月用一次的收进菜单。每个元素等重是没做决定的信号。
- **每屏留一个主决策点**，其余靠分组、过滤、渐进披露承载。密度靠组织，不靠平均。
- **导航顶层不超过 5 项**，动作按钮 1 个主 + 1~2 个次，其余收进溢出菜单。
- **分组靠邻近优先于加容器**。同一屏不要在同一个容器里再套一层容器。
- **每个决策点的可见选项控制在 4 个左右**（这一步仍受工作记忆限制），超过就分组或改成搜索。

## 色彩与语义角色

先定角色，再定色值：

- 画布面 / 抬升面
- 主文本 / 次文本 / 禁用文本
- 动作色 / 焦点色 / 选中色
- 边框与分隔线
- success / warning / error / info
- 数据类别色

规则：

- **强调色只给主操作、当前选中、状态指示**，单屏占比控制在 10% 以内。到处都在强调，等于没有强调。
- **侧栏、工具栏、面板加第二层中性色**（比内容面略冷或略暖），让「壳」和「内容」在色彩上分开。
- **对比度硬门槛**：正文与占位文字 ≥4.5:1，大字 ≥3:1，控件、图标、焦点环 ≥3:1。禁用态、遮罩层、图上的文字、浅深两套主题都要各自算过。
- **彩色底上的次要文字用该色相变暗或加透明**，不用灰。彩底灰字是最常见的一种脏。
- **新调色板用 OKLCH**，靠近白或黑时降 chroma，避免偏色。
- **层级差用显式色值**，不靠把半透明一层层叠出来。

## 深度

- **阴影带偏移 + 柔和模糊**。零偏移的彩色光晕是装饰，不是深度。
- **窗口的阴影与圆角是系统的**（见 `references/shell-windows.md`），只给窗口内部的浮层、卡片、菜单用 CSS 阴影。
- 层级越高的浮层阴影越扩散，不要所有浮层同一个阴影。

## 主题

- **跟随系统深浅色**，切换时不闪（先读完系统偏好再渲染第一帧）。
- **切主题只重映射语义角色**，不要在组件里写 `if (dark)`。
- **暗色不是反相**：重新设计面的抬升关系与对比，暗底下相邻面的亮度差要重新调。
- **强调色跟系统强调色**，用户在设置里换了蓝紫，你的应用跟着变。

## 浏览器表面

这些默认不属于任何设计系统，却最容易被看出「拼的」。全部按调色板主题化，是性价比最高的一步：

- 文本选中色与选中文字色
- 插入符颜色
- 滚动条（轨道、滑块、悬停、按下）
- 焦点环
- 链接下划线的粗细与偏移
- 表格里的数字用等宽数字（`font-variant-numeric: tabular-nums`），列的位数才对齐

## 拒绝项

这些是品类默认值，不是天条——但手里没有更好理由时别用：

- 渐变文字（强调靠字重或字号）
- 卡片左右 1px 以上的彩色边框
- 卡片套卡片
- 用同尺寸「图标 + 标题 + 一段话」卡片堆当页面结构
- hero 指标模板（大数字 + 小标签 + 辅助统计 + 强调色）
- 标题上方的引导小标签（eyebrow / kicker）
- 用 emoji 或 Unicode 字符顶替图标系统；图标要有统一笔画与重量
- 用进度环、sparkline、柔和圆角矩形冒充真实内容
- 玻璃与模糊当装饰（用系统材质做真实表面不算）
- 零模糊的硬偏移阴影（除非这个世界本来就是新粗野主义）
- 按品类而不是使用场景决定深浅色

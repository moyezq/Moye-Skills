# 复杂度与评分

## 模式

| 模式 | 目标 | 适用 |
|------|------|------|
| 忠实复刻 | 尽量保留原源码 / 布局 / 交互 | 合法源码、单文件、学技法 |
| 视觉复刻 | 外观接近，实现可换 | 无源码、官网、内容站 |
| 内容爆改 | 留节奏和视觉语法，换你的内容 | 改成自己的站 |
| 技术拆解 | 先确认真实实现 | WebGL/Canvas、分析互相矛盾 |

## L1–L6

| 级 | 类型 | 信号 | 通常可还原 | 默认边界 |
|----|------|------|------------|----------|
| L1 | 静态 HTML/CSS | 少量 JS、无框架 | 90–98% | 像素级可接近，素材版权另算 |
| L2 | CMS/企业站 | 多页、表单/新闻 | 70–90% | 前台可还原，后台不克隆 |
| L3 | React/Vue/Next 内容前端 | hydration、路由、接口取内容 | 65–90% | 数据用本地 JSON 替身 |
| L4 | 动画品牌站 | GSAP、Lenis、复杂滚动 | 50–80% | 主视觉可还原，微交互常近似 |
| L5 | WebGL/Canvas/Three | shader、物理、GPU 资源 | 30–95% | 有源码可高，没源码先拆再定 |
| L6 | SaaS/电商/登录 | 账号、支付、权限 | 展示层 | 服务端逻辑默认不克隆 |

## 复刻后评分

每项 0–5。只给能被源码、截图、运行结果支撑的分。

| 维度 | 5 | 3 | 1 |
|------|---|---|---|
| 源证据 | 源码或完整静态资源，关键结论有文件/行号 | 运行时侦察 + 资源抓取 | 目测推断 |
| 结构保真 | 信息架构、区块、断点一致 | 主区块一致 | 大概风格 |
| 视觉保真 | 字体间距颜色图片高度接近 | 主视觉接近 | 像另一个设计 |
| 动效/交互 | 滚动悬停视频 Canvas/WebGL 接近 | 只留核心交互 | 基本静态 |
| 响应式 | 桌面/平板/手机都验证 | 验 1–2 个宽度 | 移动端破版 |
| 功能完整 | 导航表单媒体外链本地都可用 | 主路径可用 | 多处死链或报错 |
| 内容替换 | 已换成你的内容，替换地图清晰 | 部分改造 | 大量原站残留 |
| 法务/部署 | 许可清楚，追踪移除，素材边界明确 | 风险已记未解 | 风险不清楚 |

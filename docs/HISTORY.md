# 已废弃的决策

问「为什么曾经那样 / 要不要复活」时读这一份；现行为什么在 [adr.md](adr.md)。按时间追加，不抄旧全文（全文留 git）。

## 2026-10-01 · 前端入口曾经是 self-frontend

- **背景**：工作树顶层只留 `self-frontend`，下面收 `self-react` / `web-clone`；入口文件叫 `BODY.md`，避免 Cursor 递归扫描嵌套 `SKILL.md`。
- **废弃原因**：整份从工作树退役，材料后来也不再保留。后继 ADR-0019。

## 2026-10-01 · 浏览器入口曾经是 self-spyder

- **背景**：`playwright-cli` 收到 `self-spyder/` 下，顶层只留薄入口。
- **废弃原因**：多一层只分流、无额外判据，占固定上下文。后继 ADR-0015。

## 2026-10-07 · 桌面壳曾经进工作树为 self-desktop-ui

- **背景**：窗口、托盘、材质等壳层与页面前端分开，单独立一份 skill。
- **废弃原因**：与 `self-frontend` 一并退出工作树。现仅 `preinstall/self-desktop-ui` 待审，不进工作树。后继 ADR-0019。

## 2026-10-08 · 操作规范不再按「改文件 / Git」分家

- **背景**：曾把 harness 操作细则拆成两份并列文件——按 `AGENT` 分节的文件操作，与独立的 git 流程。
- **原因**：细则的读者是当轮那个 harness，放通用层等于让三个 harness 互相读对方的命令。
- **做法**：改成按 harness 自包含的三份，每份同一套六块。
- **废弃原因**：分家让 git 与文件操作各占一页，一个会话常要读两份才拼得出全貌。后继 ADR-0011。

## 2026-10-12 · code-principles 去 self- 前缀

- **背景**：`self-code-principles` 改名为 `code-principles`，13 条正文当时仍在工作树。
- **废弃原因**：随后整份退役，材料已不保留。后继 ADR-0028。
